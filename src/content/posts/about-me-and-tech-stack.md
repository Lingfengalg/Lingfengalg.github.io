## 我的技术栈

### Flutter 与 Dart

我使用 Flutter 开发桌面端和跨平台应用，关注状态管理、网络通信、数据可视化以及 Windows 客户端体验。目前最主要的实践项目是 [StudyOS](https://github.com/Lingfengalg/StudyOS)。

### Python 与 FastAPI

Python 主要用于后端服务、自动化和 AI 应用。StudyOS 的本地后端使用 FastAPI，对外提供 REST API，并通过 SQLite 保存学习记录、错题、成绩和计划等数据。

### C、C++ 与计算机基础

我也在持续学习 C、C++、CMake 和计算机系统知识。相比只完成某个功能，我更希望理解代码下面实际发生了什么，并逐渐形成可靠的软件工程能力。

### AI 应用开发

我关注大模型在真实软件中的落地，包括 OpenAI 兼容接口、AI Agent、工具调用、OCR 与结构化数据处理。对我来说，AI 不只是聊天窗口，而是可以参与具体工作流的能力模块。

## 正在做的项目：StudyOS

StudyOS 是一个桌面优先的综合学习系统，目前采用以下架构：

- Flutter Windows 客户端
- FastAPI 本地后端
- SQLite 数据库
- 面向学习场景的 AI 助手与工具调用

它包含今日学习、错题整理、考试成绩、备考专项、复盘计划和数据管理等模块。我会在后续文章中逐步记录它的设计与开发过程。
